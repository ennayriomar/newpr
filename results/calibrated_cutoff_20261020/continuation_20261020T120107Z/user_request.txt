ARCHITECTURE
Use one shared frozen DINOv2 ViT-L/14 register encoder:

                              ┌─ PCA subspace ─ reconstruction residual ─┐
Image → frozen patch features ┤                                          ├→ score fusion
                              └─ normal memory bank ─ NN cosine distance ┘

Normal support images fit the PCA subspace and populate the memory bank.
Query images are scored against those fitted components.

Preserve the original implementation:
- Global PCA retaining 95% variance.
- Existing normalized PCA-residual correction.
- Additive fusion: NN score + lambda × normalized PCA residual.
- Existing controlled lambda, expected to be 0.25; verify it in protocol.json.
- Exact recorded layers, feature aggregation, augmentations and normalization.
- Full-field resize=448, crop=448.
- Image score: mean of the highest-scoring 1% of map pixels.
- No gradient training, optimizer or epochs.

These are SubspaceAD-inspired and VisionAD-inspired branches, not automatically
faithful reproductions of the official methods. Do not claim otherwise.
