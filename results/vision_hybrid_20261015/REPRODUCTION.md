# Reproduce or use the completed research model

The complete archive retains every fitted bank and the source needed for
numerical replay. `reproduction/tools` contains project code and installers;
`reproduction/vendor/dinov2` contains pinned licensed Meta source. The
foundation checkpoint and raw datasets are separate online downloads.
`reference_evidence.json` attributes the inspected recipe without copying its
unlicensed source. Model features retain dataset licensing conditions.

For portable prediction use the selected `model` prefix in a category/draw
folder, the bundled source and an official checksum-verified checkpoint with
`safe_iad.vision_hybrid_cli predict`. Do not use the unselected `fit_model`
prefix for operational decisions. The separate selected model NPZ is a
hardlink alias to the same fitted support features, not a second training run.

To perform a fresh declared study, copy `configs/vision_hybrid_20261015.json`,
update roots/encoder paths and set its three historical manifest paths to the
corresponding files under `reproduction/inputs`. Choose a new output directory.
These bundled manifests preserve the native support/query selection and
available-history exclusions. Do not erase history to obtain more attractive
samples. The existing frozen plan uses original absolute paths; copied reports
cannot satisfy its input ledgers without restoring those paths and bytes.

The run uses 100 development images and 100 reserved image IDs in five other
categories, two support draws, one original normal per target bank and no
extra target calibration images. Support augmentation does not increase the
original-shot budget. Do not retune on the reserved evaluation outcomes.
The paired interval holds categories fixed and has only two support draws.
There is no full-paper benchmark or calibrated production guarantee.
